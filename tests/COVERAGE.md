# Покрытие host-тестов прошивки

Host-тесты собираются для компьютера с тестовыми заглушками FreeRTOS и LwIP. Они позволяют измерять покрытие логики, которую можно проверить без STM32. Они не измеряют выполнение прошивки на контроллере.

Нужны CMake 3.20 или новее, Ninja, Clang, CTest, `llvm-profdata` и `llvm-cov`; эти команды должны быть доступны в `PATH`. Скрипт использует Ninja, чтобы Clang был явным компилятором host-тестов.

Из корня репозитория в Windows PowerShell запустите:

```powershell
powershell -NoProfile -File tests/coverage.ps1
```

Скрипт создаёт отдельную сборку `cmake-build-coverage`, запускает все зарегистрированные host-тесты и формирует текстовый отчёт с покрытием строк, функций и ветвей, а также HTML-отчёт. Результаты лежат в новой папке `coverage-<timestamp>` внутри каталога сборки. Их не нужно добавлять в Git.

CI проверяет каждый файл в LLVM-отчёте отдельно: строки, функции и ветви должны иметь покрытие 100%; иначе job завершается ошибкой. Host-тестовые executable- и library-targets автоматически собираются с LLVM-инструментированием, а CI и локальный скрипт находят test executable автоматически. Новый модуль нужно включить в host-test target и зарегистрировать тесты: исходники, не собранные в host-тестах, в отчёт покрытия не попадают.

Отчёт исключает тестовые файлы, `Core`, `Drivers`, `Middlewares` и `LWIP/App`; исходники `APP`, `BSP` и `LWIP/Target` остаются в отчёте. Неинструментированные файлы не учитываются. Измерение показывает только участки кода, выполненные тестами; процент покрытия сам по себе не подтверждает корректность поведения.
